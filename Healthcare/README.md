# GenAIForge · Patient Access Command Center

**90-second pitch:** Clinics lose patients to no-shows and after-hours questions. This demo is a **Patient Access Command Center** — 24/7 booking, no-show risk on every slot, protocol intake, and a floating Patient Assistant that **never diagnoses**. Clinicians stay in charge; AI only books, reminds, and routes.

## Open the demo

Open `Healthcare/index.html` in a browser (or serve the folder).

## What to show

1. **Hero proofs** — 24/7 access · no-show ↓ · **0 diagnoses by AI**
2. **Clinic tabs** — Mumbai / Bengaluru / Hyderabad
3. **Risk calendar** — low / mid / high badges + reminder status; click a slot → intake (never a diagnosis)
4. **Patient Assistant** (right sidebar) — try:
   - *Book a GP today* → calendar updates
   - *Send reminder for high-risk slot* → extra nudge
   - *Is this rash serious?* → guardrail + escalation queue (no diagnosis)
5. **Protocols** — Respiratory / Pediatric fever / Appointment routing
6. **Escalation queue** — PII masked until **Claim**
7. **Theme toggle** — light clinical teal / soft navy dark (`gf-theme`)

## Product line

Maps to GenAIForge **Patient Engagement & Triage** — assistive only, not a medical device.
