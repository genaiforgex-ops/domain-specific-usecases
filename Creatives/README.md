# GenAIForge · Campaign Studio

Governed creative production for marketing teams — from brief to approved assets — with brand guardrails, human approvals, ROI proof, and a live **industry news pulse**.

**Who it is for:** CMOs, brand leads, creative ops, and agencies evaluating AI for campaign scale without losing control.

---

## What this demo shows

- End-to-end workflow: **Briefs → Copies → Design → Approvals**
- **Brand guardrails** (tone, banned claims, AI disclosure) before publish
- **HITL** approval gates and a full activity / audit timeline
- Buyer surfaces: **ROI vs agency**, Pilot vs Production, trust chips, procurement FAQ
- **Real 2025–2026 marketing news** with GenAIForge “next actions” (Nike, Apple, retail media, disclosure regulation, and more)

Accent color: bronze `#B8956C`. Theme toggle included. Demo badge on all screens.

## How to open

```bash
open Creatives/index.html
```

```bash
cd Creatives
python3 -m http.server 8080
# → http://localhost:8080
```

Requires network once for Google Fonts. No build step.

## Recommended walkthrough (≈2 minutes)

| Step | Panel | What to say / do |
| --- | --- | --- |
| 1 | **Home** | Open the hero “why buy” strip (agency cost avoided, cycle time, brand checks). Scroll the **marketing news pulse**. Switch role. Start the **numbered tour**. |
| 2 | **ROI / Buy** | Show cost vs agency (including retail-media format sprawl), Pilot vs Production packages, trust chips, integrations, FAQ, audit export. |
| 3 | **Guardrails** | Tone rules, banned claims, AI disclosure lockup, prompt studio, RACI / HITL matrix. |
| 4 | **Briefs → Copies → Design** | Walk ForgePay festive creative. Call out news-seeded briefs (retail media pack, creator disclosure pack). |
| 5 | **Calendar** | Launch plan by channel and date (including Amazon Ads / Walmart Connect). |
| 6 | **Assets + Inbox** | Approved library; stakeholder mentions with SLAs; news items that deep-link into briefs. |
| 7 | **Approvals → Performance → Activity** | HITL gates, performance with market context, full audit timeline. |
