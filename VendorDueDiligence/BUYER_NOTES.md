# Vendor Due Diligence — Buyer notes (sales)

*Updated Sep 2026 with TPRM / examiner research. Citations are public themes used illustratively; vendor records remain fictional demo data.*

## What BFSI TPRM buyers ask

| Theme | Typical ask | Demo surface |
| --- | --- | --- |
| **Lifecycle, not snapshot** | Register → screen → decide → monitor | Dashboard narrative · Monitor |
| **Continuous monitoring** | Alerts, re-screen cadence, cert expiry, cyber score | Monitor panel |
| **Questionnaires + evidence** | Assignment status, overdue packs, exportable ZIP | Questionnaires |
| **Inherent vs residual** | Risk scoring after controls + HITL acceptance | Risk scoring gauges |
| **Nth-party / fourth-party** | Subprocessors, flow-down diligence | Monitor nth-party alert · Q6 form · Controls |
| **Control mapping** | Findings → ISO/SOC/DORA/NIST/OCC/BIS | Policy / controls |
| **Audit-ready** | Examiner pack without scramble | Audit pack export |
| **Procurement checklist** | Sanctions, UBO, financials, cyber, residency | Procurement buyer view |
| **HITL** | Residual risk acceptance needs sign-off | DD sign-off · Scoring |

## Pitch line
