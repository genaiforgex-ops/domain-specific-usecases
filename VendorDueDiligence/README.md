## 2-minute client pitch

1. **Dashboard** — Narrative rail **Register → Screen → Decide → Monitor**. KPIs include critical alerts. Trust/integrations strip → **Procurement**. **TPRM research pulse** cites continuous-exam / BIS / OCC themes with GenAIForge next actions.
2. **Vendors** — Filter registry; select **CloudNest** (context chip sticks across all panels).
3. **Due Diligence** — Run screening animation → score/decision/conditions (incl. nth-party change notice) → jump to Report.
4. **Report** — Red/green flags, tabs, PDF export, HITL sign-off.
5. **Monitoring** — Continuous alerts (certs, cyber, fourth-party, questionnaires) + cadence; click alert to switch vendor context.
6. **Questionnaires** — Assignment status/progress incl. fourth-party map; export forms pack.
7. **Risk scoring** — Inherent vs residual gauges with examiner-ready narrative; accept residual risk (HITL).
8. **Controls + Audit pack** — Findings → framework mapping (DORA/NIST/OCC/BIS); build examiner ZIP with nth-party snapshot.
9. **Procurement** — Expanded TPRM checklist · Pilot/Production packages · trust strip.
10. **M1 Snapshot** — Outsourcing classification for selected vendor.
