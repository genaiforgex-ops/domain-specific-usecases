# GenAIForge · BFSI Voice Command Center

Premium demo of an **AI Advisory & Collections Voice Agent** for Indian BFSI — ROI proof, DPD playbooks, customer 360, and RBI/SEBI compliance rails on a live call floor.

**Who it is for:** Collections, advisory, compliance, and digital banking leaders evaluating voice AI with auditability and fair-practices controls.

---

## What this demo shows

- ROI hero: human cost saved, calls today, 100% audited
- Campaign intelligence: Collections / SIP / KYC / Advisory with DPD (or stage) funnels
- Live call floor: NOW TALKING, waveform, campaign-aware disclaimers
- Customer 360 card (product, outstanding, DPD, consent, DND, masked PII)
- Outcomes: UPI payment link (PTP), RM meeting, hardship → human, sealed audit hash
- Compliance cockpit: calling window, recording disclosure, PII mask, DND scrub, audit hash

Research-aligned themes: calling hours, recording disclosure, hardship escalation, cost vs human floor.

---

## How to open

```bash
open Banking/index.html
```

Or:

```bash
cd Banking
python3 -m http.server 8080
# → http://localhost:8080
```

Requires network once for Google Fonts (Sora + IBM Plex Sans). No build step.

## Recommended walkthrough (≈90 seconds)

| Time | Focus | What to do |
| --- | --- | --- |
| 0:00 | **ROI hero** | Show human cost saved, calls today, audited %. Mention cost/call AI vs human. |
| 0:15 | **Campaign intelligence** | Switch Collections / SIP / KYC / Advisory and region. Point to funnel + playbook. |
| 0:30 | **Live demo call** | Join the hottest queue item. Show NOW TALKING, timer, SEBI/RBI disclaimer. |
| 0:40 | **Customer 360** | Walk LMS-style card: product, DPD, last pay, consent, DND, masked PAN/phone. |
| 0:55 | **Advance conversation** | Step Hindi / Marathi / Tamil / English scripts. Trigger PTP, RM booking, hardship escalate, or seal audit. |
| 1:15 | **Compliance cockpit** | Calling window 08:00–19:00 IST · recording disclosed · PII masked · DND scrubbed · audit hash. |
| 1:25 | **Theme** | Toggle light/dark (`gf-theme` in localStorage). |
