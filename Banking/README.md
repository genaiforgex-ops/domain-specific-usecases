## 90-second client pitch

### 0:00 — ROI hero
Three proofs: **human cost saved today**, **calls today**, **100% audited**. Language strip. Cost/call AI vs human.

### 0:15 — Campaign intelligence
Switch **Collections / SIP / KYC / Advisory** and region. DPD (or stage) funnel with volume + cure % + playbook. Connect sparkline.

### 0:30 — Start live demo call
CTA joins the hottest queue item. See **NOW TALKING**, waveform, timer, campaign-aware **SEBI/RBI disclaimer**.

### 0:40 — Customer 360
LMS-style card: product, outstanding, DPD bucket, last pay, consent, DND, masked PAN/phone.

### 0:55 — Advance conversation
Step through Hindi / Marathi / Tamil / English scripts. When prompted:
- **Send UPI payment link** (PTP)
- **Book RM meeting** (advisory / KYC)
- **Escalate hardship → human** (Fair Practices story)
- **Seal audit trail** (immutable hash)

### 1:15 — Compliance cockpit
Calling window 08:00–19:00 IST · Recording disclosed · PII masked · DND scrubbed · Audit hash.

### 1:25 — Theme
Sun/moon toggle · `gf-theme` in localStorage · dark ink default · cool bank light (no cream).
